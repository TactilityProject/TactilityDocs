# Files

The Files app browses the storage of the device: internal storage, the SD card and USB drives.

## Browsing

- **Tap a folder** to open it. The up button in the toolbar goes to the parent folder.
- **Tap a file** to open it: text files open in Notes, images in the image viewer, `.app` packages ask to be installed and executables are run.
- **Swipe left or right** to go to the next or previous page, or use the `<` and `>` buttons.
- The **⋮** button creates a new file or folder, and pastes what is on the clipboard. It is hidden at the root.

## Actions

**Long press** a file or folder to show its actions: copy, cut, paste, rename and delete. The actions also appear for a USB drive at the root, where they only offer eject.

Copied or cut items stay on the clipboard until you paste them. Open another folder, then paste with the paste action or the ⋮ button. When an item with the same name exists, you are asked whether to overwrite it.

## Selecting multiple items

Copy, cut and delete work on several items at once.

1. **Long press** the first item.
2. **Tap** or **long press** more items to add them to the selection. Tap or long press a selected item to remove it. Selected items are highlighted.
3. Pick an action. Rename is only available for a single item.

The selection only covers the current folder. It is cleared when you open another folder, change page, or finish an action. Without items selected, a tap opens a folder or file as usual.

To clear the selection without doing anything, deselect all items or press the **⋮** button.

## Keyboard

| Key | Action |
|---|---|
| Arrow keys | Move between the items |
| Enter | Open the focused item, or add it to or remove it from the selection |
| Space | Select the focused item, like a long press. Press it on more items to add them. |
| `c` | Copy the selection |
| `x` | Cut the selection |
| `v` | Paste |
| `r` | Rename the selected item |
| Delete or Backspace | Delete the selection, after a confirmation |
| Esc | Clear the selection |

The `c`, `x`, `v` and `r` keys work while items are selected. Without a selection, Delete, Backspace and `r` act on the focused item.
