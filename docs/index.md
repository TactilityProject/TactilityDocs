## About these docs

The documentation is written per Tactility version. Pick the version that matches the firmware on your device or the SDK that you build with.

- To install Tactility or to see which devices it runs on, go to [tactilityproject.org](https://tactilityproject.org).
- Bugs and suggestions can be reported on [GitHub](https://github.com/TactilityProject/Tactility/issues).
- For questions, see [Support](support.md).
